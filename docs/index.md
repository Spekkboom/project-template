# Project Template

Welcome to the Project Template documentation!

This is a simple Python project that demonstrates best practices for:

- Project structure with `src/` layout
- Unit testing with pytest
- Documentation with MkDocs
- Dependency management with uv

## Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/project-template.git
cd project-template

# Install dependencies
uv sync

# Run tests
uv run pytest

# Serve documentation
uv run mkdocs serve
```
